About STT Cloud

Welcome to STT cloud! You would be wondering...what is this? Well, this is like a bulletin board but you can post what you only say. Yes, some of you guys have already noticed, SST means Speach To Text.

Here's a list of the features of this "bulletin board"

  • "The audio data will be transcribed and then once it's ready it'll be shown on the board."
  • "There's no user name, no thread name, of cource no password too."
  • "You can post whatever you want but be carefull not to post anything credential"
  • "Any language is welcome to use, thanks to the modern STT language model, Whisper "
